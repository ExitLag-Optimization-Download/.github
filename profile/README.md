## 🧠 Overview

ExitLag is a Windows network optimization utility built around improving the connection between PC games and their online servers. It analyzes available routes and can use alternative network paths for selected game traffic, helping address connection problems associated with inefficient routing, unstable latency, packet loss, and inconsistent network conditions.

The application provides a dedicated interface for selecting games, configuring connection behavior, and monitoring network performance. Its optimization tools can be applied on a per-game basis, making it possible to maintain different connection configurations for different titles and server regions.

## Additional Information for Windows Users

ExitLag operates primarily on the network side of the gaming experience, so it does not directly increase the rendering performance of a graphics card or processor. Its results depend on factors such as ISP routing, geographic distance, server location, network congestion, and the infrastructure used by the individual game.

For consistent results, select the correct game profile and region, maintain a stable internet connection, and avoid unnecessary bandwidth-heavy applications during gameplay. Network improvements can vary between games and locations, so the available routing options should be evaluated according to the connection being used.
